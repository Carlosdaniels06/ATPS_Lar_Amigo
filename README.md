# ATPS - Lar Amigo

Projeto acadêmico desenvolvido em HTML e CSS para a ATPS de Design para WEB.

## Páginas
- index.html — página inicial
- adote.html — animais disponíveis para adoção
- contato.html — formulário de contato e formas de ajudar
- style.css — estilização e responsividade
- imagens/ — imagens fictícias em SVG

## Como testar
Abra o arquivo `index.html` no navegador.

## Roteiro rápido do vídeo (até 3 minutos)
1. Apresente a proposta do Lar Amigo.
2. Mostre a página inicial e o menu.
3. Acesse "Adote" e mostre os cards dos animais e os botões.
4. Acesse "Contato" e mostre o formulário.
5. Mostre rapidamente os arquivos HTML e o style.css.
6. Explique que o site possui três páginas, imagens, formulário, navegação e responsividade.
